# Rider–Waite–Smith Major Arcana

- Artwork: Pamela Colman Smith, directed by Arthur Edward Waite.
- Original publication: 1909/1910 Rider–Waite–Smith tarot deck.
- Source pack: sixseeds/tarot-api, commit
  71825eed74683305b139a669b23ca5dc12f76857, files cards/ar00.jpg through
  cards/ar21.jpg.
- Upstream description: the 78 Rider–Waite card images are public domain.
- Independent provenance check: Wikimedia Commons identifies the original
  Rider–Waite deck as public domain; later colorized variants can have separate
  rights, so this project pins the original scanned set and verifies every JPG
  by SHA-256 during the build.

The App uses these images only for an offline, entertainment-only daily card
view. The locally written Chinese interpretation catalog is project code and
does not copy modern tarot guide text.
