The bundled `index.html` adapts the original **Ruota della Fortuna** by
Copper (29-Cu), revision `8d62036de5c3e0cdb18ac082c77a7051b55ce43a`.
The machine layout, tag list, interactions and animations come from its
original `index.html`; the changes bundle fonts offline and add the Android
confirmation bridge and an attribution link. Original license: `LICENSE`.
Based on Ruota della Fortuna by Copper (29-Cu):
https://github.com/29-Cu/Ruota-della-Fortuna

Bundled fonts have separate SIL Open Font Licenses in `fonts/OFL-*.txt`:
Rye, Cinzel and a subset of Noto Serif SC for the UI text. These fonts are
distributed only to render the original design without a network dependency.
