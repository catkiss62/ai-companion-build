# v0.41.18 总设置信息架构与保存语义

目标构建：`v0.41.18+157 / schema 43`。

## 目标

把原本超过一千行、一次保存二十多项状态的总设置页拆成六个按用途进入的页面，同时保留头像侧栏的常用快捷设置。两种入口必须读取和写入同一 setting key，不能复制状态或互相覆盖。

## 六个入口

1. **模型与联网**：DeepSeek、千问视觉、Tavily、Agnes、公开网页发现。
2. **记忆与成长**：记忆抽取/整理/淡化、Reference、规则、Thought、Self-Drive、AI Self、关系连续性和 Session。
3. **主动联系与感知**：主动频率、节奏学习、通知方式、隐私、提示音、主动语音和环境感知。
4. **语音与聊天呈现**：本地 TTS、情绪、聊天画面和文字演出。
5. **设备与数据**：Active Brain、新上下文、设备接管、备份、权限和悬浮入口。
6. **诊断与开发**：快速自检、深度验收、运行维护和会推进真实状态的开发工具。

## 保存规则

- bool/enum 立即写入；slider 在拖动结束时写入。
- API Key、Endpoint、模型名、额外来源和 TTS 替换 JSON 只由所属小节保存。
- Endpoint 验证成功后才保存同小节 Key，避免半保存配置。
- `Active Brain`、开始新上下文、清除诊断和回复任务处理保持独立动作与确认，不进入普通保存。
- 侧栏和总设置继续使用现有 keys；schema 43 与备份 protocol 5 不变。

## 自检分层

- 服务旁的“连接测试”会真实联网并消耗少量额度，但不写聊天或记忆。
- “快速自检”是日常主入口，以读取状态和导出脱敏报告为主。
- “深度自检/综合验收”可能校验和初始化本地 TTS。
- “运行维护/开发工具”可能安排通知、调用模型、产生主动消息或推进 Thought/Self-Drive 等真实状态，必须显式标注副作用。

## 同包小修改

- `chat_dialogue_color=purple` 的三端映射统一改为 `#D4BBFC`，不迁移已保存枚举。
- follow-up 可见标签统一为“想起之前的话”，避免把数日前的话题误写成“刚才”。

## 不在本批

不修改 Phase 2A、Phase 2B、Desire 系数、Self-Drive 调度、联网选题、屏幕观察、悬浮生命周期、数据库 schema 或备份格式。该包是 Phase 0～4 之间的第二个基础体验插队任务，不改变大型阶段顺序。
