## 实现

- 公共JEV处理器移除近概率强制中性标签；已知同义的玩闹/游戏授权分组保留，分组接近也不再编造第三标签。返回语义赢家、概率与独立不确定标记，合批数量不变、失败仍走原短请求降级，不因有效但犹豫新增模型重试。领域专属的心境/网页等证据准入规则仍是独立消费策略，诊断分别记录semantic_choice与consumer_evidence_policy，不误称原始分类改变。
- 任务仍保存真实动作与目标；犹豫字段独立保存，目标授权与工具执行暂缓。普通/模型两条执行路径均受同一deferred集合约束；不把犹豫说成无请求，也不允许旧关键词绕过。游戏态度不明确时不写新态度，突破判断不明确时保持原形态，交付证据不明确时不确认已交付。原来源绑定缓存键保持稳定，新增字段兼容旧缓存。
- 工具分类增加混合任务与单次/多步骤范围，日期题仍并入已有短判断。唯一明确的房间可先读其已授权部分，只有明确单次才允许快捷结束；歧义/候选缺失先搜索目录，完整有效的语义no不被旧自然语言读路由覆盖。明确系统命令、屏幕授权与原写权限门保留。
- 房间候选增加当前本地时间/UTC偏移、实际首末发言、关闭时间；更新时间明确不是发言时间。目录可按实际发言日期范围查找最近候选之外的房间。新语义请求读取必须给实际ID或句柄，不能用空目标默认为最新。
- 摘要成功不再无条件关闭整轮工具循环；只有明确单次摘要且其他目标均已满足才快捷完成。实际多步骤任务开放已有只读工具范围并继续核验，普通闲聊不因此新增完整规划。
- 明确多步骤工具任务的规划上限为5轮，原普通工具任务3轮、普通调用上限6次及游戏/深思独立上限保持。否则目录→原文→网页搜索→网页读取四个依赖步骤仍会被3轮预算截断。已知房间先读可节省一次规划，但不提前结束剩余目标。新增真实runner四步依赖回归；不靠全面放大每轮闲聊权限解决。
- 普通闲聊没有实际工具需求时不注入工具规划提示；没有游戏/创作动作时，其独立目标题的犹豫不会制造澄清任务。原始概率仍留在诊断，执行约束只消费相关字段，避免工具修复干扰日常说话。
- 分类完全不可用时，旧房间命令也先返回目录；普通用户轮实际读取始终要求ID或句柄。不能把“无法判断”再解释为“用户要求最新房间”。明确系统/屏幕命令及其他写授权保持原流程；目录带当前时间供既有Agent核对相对日期。
