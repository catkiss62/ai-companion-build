## 本轮实现

- 独立19情绪渲染值及 normal，自然开心不自动启用爱心眼。特殊眼型四选一；脸部效果可叠加；特殊眼型会压住 wink。支持角色左／右 wink 及吐舌 wink，不含比耶或菜菜道具。
- 11种按键预览：黑脸、落泪、呆萌圈圈眼、爱心眼、><眼、嫌弃眼、脸红、加载、憨憨兔牙、大钢盆、流冷汗。泪滴／高光使用原包 IDLE 的白名单曲线，未将其误认成全身待机；加载用 CDI 中的 Param140，流汗用 Sweat1/2，均按实际 Core 范围独立循环。Param55/56/57/58 属于尾巴的光1～4，即使出现在手势片段中也过滤，不混入加载／手臂所有者。
- 狗尾草、扶胸、竖食指各用原包六个进出动作。motion3 的 Loop 即使为 true 也按一次性进出处理；保持有界，三组手势共用一个互斥控制器，中断从当前姿态平滑接回程再进入下一组。禁止直接持久化 Movement 开关。
- DeepSeek 专用 JEV catalog / usageLane，一次 chooseMany 同时决定四拍与可选真实中文语音分段。使用 AngleX/Y/Z、PositionX/Y/Z、LeanInput 等真实输入轴，拒绝物理输出轴／衣装／形态／手势曲线注入；头目标上限14、身体8，整模偏移3.5%／倾斜3°，Core 上下限再次约束。明确贴近语义才平滑前倾至-30后回位。
- PCM 播放心跳覆盖全部临时嘴部参数，语音中的无声片段也不交还嘴型；单次物理后再次断言嘴部所有权，嘴型装扮 MouthPressLipOpen 保留。真实音频分段核对 lease、message、audible、中文、实际朗读指纹和推进的 playhead；静音／暂停／错文本释放，重播只复用已有方案。切换模型后等待真实 ready 再取得 owner，最长约15秒，可被新回复／隐藏／模型替换取消，音频不等待此规划。
- 原生独立命令与 owner 同时带 profile、profile_generation、asset/loadIdentity、catalog、execution_id/epoch。GL 执行前再次验证，语音另有序号围栏，避免排队的旧停止指令清掉新 cue。后台／隐藏／编辑会停表演；语音表演另有700ms本地失联释放。
- DeepSeek Jev 开关使用第一阶段预留的 deepseek_motion.jevEnabled，进入原有双模型存档白名单，不改菜菜 caicai_jev_motion。手动预览和参数校准不保存临时表情。小豆丁沿用可调大小，增加不高兴的嘴型／压眉／鼓脸；语音中嘴仍归PCM。
