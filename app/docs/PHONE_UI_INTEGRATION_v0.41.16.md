# v0.41.16 查手机与快捷界面整合合同

状态：`IMPLEMENTED / LOCAL STATIC REVIEW PENDING / CI PENDING / TRUE DEVICE PENDING`

本批是 Phase 2A 自然观察期间的基础体验插队包，不是人格成长 Phase 2B。它不得修改 Desire、Thought、Self-Drive、联网评价、人格学习候选或普通回复 bias；schema 保持 43。

## 1. 查手机

- 心情图始终显示截至今天的最近 7 个设备本地自然日。空日期保留横轴位置，同日多条只在自己的日期槽内错开。
- 购物车每天至多生成一次并持久化 6 件商品。DeepSeek 只获得固定的公开鲸鱼娘角色种子、日期 nonce 与近期标题；不得读取聊天、Memory、Desire、人格学习候选或 AI Self。
- 购物车输出必须恰好 6 件、标题唯一、价格 1～99 鲸币，正常与搞怪各 2～4 件。API 缺失、18 秒内未完成、失败或格式不合格时使用 18 件正常＋18 件搞怪的本地兜底池，并尽量避开近期标题。
- 塔罗结果、抽牌与牌义不变。每个 Tab 的牌面仅在当天该牌第一次真正可见时做一次约 1050 ms 的透视横向整周旋转；逆位最终仍保持逆位。系统请求减少动态效果时直接展示终态。

## 2. 沉浸房间与文字层级

- 沉浸房间复用普通聊天的底部可拖动面板形态，但使用独立 `immersive_panel_fraction`，范围 0.42～0.94；不得联动普通聊天的 `chat_panel_fraction`。
- 只改布局，不改沉浸 prompt、房间 Memory、成人关系方向、Reality Identity 或 Session 隔离。
- 全局仍是暗色主题。标题和关键值用高强调色，说明、摘要、帮助文字使用语义次级灰；禁止把所有非标题机械改黑导致暗色页面不可读。

## 3. 快捷侧栏与状态页

- `查手机`、`沉浸房间`、`性格试穿`保持三个独立入口。
- 设置入口拆为 `主动联系`、`聊天画面`、`语音与情绪`、`文字演出`，继续写入原有 setting key，不复制第二套配置。
- `她现在的状态`只读显示 8 项欲望和 9 项萌属性的“当前值 / 长期基线”。进入和刷新页面不得推进 heartbeat、写 baseline、触发 Self-Drive、调用 API 或展示 Thought/候选/内部推理。
- 总设置仅保留入口；其六域分类、自检分层与共享保存重构属于第二步，必须先单独审计当前 `_save()` 语义再实现。
