## 存档核查边界（只读）

- SnapshotService通过db.exportAll读取本地已保留状态。普通messages与immersive_messages整行导出，含正式正文与已保存reasoning；memory_items、证据、conversation_summaries也同时导出，不是只保存整理后的记忆。设置内的模型对谈、手机内容、作品状态等一并保存。
- 导出限于当时仍在数据库及所引用文件中的内容；已删除/回档丢弃的消息、未提交的临时输出不保证成为永久原文。完成的维护post_turn_jobs被排除；生成任务、事件和诊断等实际持久数据按既有导出规则保留。
- 附件、相册与共享媒体按引用导出，包含原图和缩略图；共享blob有引用计数与摘要标识。JPEG等已压缩图片再进入ZIP时节省有限。聊天正文/reasoning、事件轨迹、生成任务、网页资料、作品、记忆证据和JEV/用量诊断也会增长；部分数据本来用于可恢复性/审计，不能只按最终记忆条数估算存档。
- 用户存档只做本地只读统计，不修改、重新打包或清理，不改导出/导入/压缩/保留策略。私有统计、正文、资源路径与凭据不提交公开仓库。回档样本不能用于直接推断正常使用的增长速度；当前版本体积需以新的导出测量为准。
