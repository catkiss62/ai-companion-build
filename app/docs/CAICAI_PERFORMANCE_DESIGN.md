## 所有权与节奏

- 当地循环的唯一所有者是每个聊天舞台的 `CaicaiGL` 线程；UI 只提交命令，不另起动画循环。Jev 一轮一次批量选择，没有每帧 API 调用。
- 底层连续待机 → 菜菜情绪 → 有界对话参数 → 当前触摸注意 → 显式原装预设；嘴张开由真实 PCM 口型拥有。变形/配件/物理仍由原菜菜实现处理。
- 待机转头基线幅度 17，点头 12，歪头 9，并叠加完整起落的强调短语；身体 X/Y/Z 分别约 7/5/7。实际每个参数仍遵守原模型 min/max。
- 永久装扮不参加临时预设清理；聊天十九情绪保持到下次情绪切换；“完全静止”仍可用，“自主待机”释放短计划并恢复运动。
- 固定 −18 仅小豆丁形态结算。普通形态保留互动/自发贡献、严肃降温和小时衰减。没有证据支持桌宠尺寸改动，本次不改。
