# 菜菜 +286 表演调节

## 回退基准

用户确认 +285 功能成功（已知输入法拉伸、动作观感不足）。基准功能提交 `6cfca5ae303f384283a653d1627ff4a548150322`，APK SHA256 `0f28b4dd43a2b5ffe00bedcd21878984c086cbe077d22d3433199f6b454968c6`。本轮保留其导入、GLSurfaceView、第二通道路由和桌宠默认值。

## Jev 实际合同

每条回复一次 chooseMany：四拍各6个参数通道，加各拍幅度/整模动作，再加全局节奏、原装表情、原装动作、持续情绪，最多36题。没有每帧请求，不按 confidence 衰减幅度。普通对话默认鲜明、明快，提示明确采用夸张虚拟主播表演；自然待机仍可选，不为了动作强改情绪。

- 幅度：轻巧0.65、鲜明1、夸张1.2，只作用头/身/整模，不放大嘴眼表情；目标按真实参数上下界夹紧。头部27/24是模型参数单位，不是实际旋转角度。
- 节奏：每拍1/0.78/0.62秒；过渡占一拍28%。本地速度设置再统一调节待机和参数/整模计划。
- 整模：左右探身（模型参考宽度±10%，配合倾斜±3度）、小腿支点左右倾（±7度和±2.5%位移），可选不位移。与头身组合；本地待机也使用同一根位移通道。
- 根位移与 Cubism 参数分开存储。所有校准结束后每个绘制pass恰好施加一次共同矩阵；按像素等比旋转，主模型和三配件共享矩阵。逆变换用于摸头命中；编辑时静止根位移。
- 优先级：摸头短时独占 > 新到的 Jev/视线；手动原装预设保持4.5秒；普通对话动作完成后返回实时待机。呼吸/音频口型仍归原主人。

## 设置与观察

默认幅度100%、速度100%是本轮更活跃的基准，不是旧版幅度。范围分别50–150%、65–160%；支点从模型顶部向下默认88%，可调65–98%。四个整模预览和现有摸头按钮用于单项比较。屏幕外遮挡不算拉伸；重点检查头宽/身长比例、三配件连接、手指摸头命中。

键盘期间 Flutter 舞台保持关闭键盘时的尺寸；横竖屏变化重建尺寸基准；原生 onSurfaceChanged 同步主/配件 Cubism render target，避免只有 glViewport 更新。日志记录 surface buffer/view/IME 尺寸；此代码缺口成立，但不先把键盘延迟断言为同一根因。触摸由露出舞台的 Flutter Listener 转发，聊天遮挡区域不会穿透触发摸头；全界面 Activity 观察仍提供视线输入。

本轮没有取得参考 APK 的当前可执行文件，不声称逐条复现其曲线。Java测试覆盖矩阵组合、像素比例、支点与逆映射；参数计划测试覆盖根通道隔离/回落，Dart测试覆盖请求和IME尺寸策略；原生冒烟增加实际SurfaceView连续缩放不重建EGL。空GL测试不代表私有模型画面验收。
