# v0.41.42 · Phase 3A AI 兴趣证据层

## 目标与边界

本包只建立 AI 自身兴趣的事实证据层，不让未成熟或已成熟的兴趣进入普通 Prompt，不改变自主联网选题，不触发主动消息，也不改动四个行为世界书、主人格、动态表达或角色扮演。

Phase 3B 才会讨论成熟兴趣如何有限参与自主选题；Phase 3C 才会讨论长期消费与习惯。3A 真机未通过前，后两阶段保持关闭。

## 可计入的真实证据

- 自主公网工具已经完成 Search → Extract → Agnes → DeepSeek 语义评价，并成功提交一条 `verified + valid` 终态结果；整条管线只算一个事件簇。
- 已验证的公网候选后来真的通过主动消息分享成功。
- 用户对上述 AI 主动分享给出明确的投入/解决反馈，作为正证据。
- 用户明确拒绝或把话题转走，作为反证。

以下来源不能生成兴趣：用户主动要求的联网查询、日记或随笔、情绪投射、随机塔罗、生成购物车、模型自述、角色扮演、同一管线的重复步骤、无回应以及仅表示“稍后再说”的时间反馈。

## 成熟合同

- 新候选只能由真实自主终态正证据创建；用户反馈不能凭空创建候选。
- 至少两个不同本地日期上的自主正证据事件簇，才可能从 `forming` 进入 `established`。
- 同一天重复搜索、阅读、评价或分享再多次，都不能绕过跨日期门槛。
- 活跃反证权重达到或超过正证据时进入 `contradicted`。
- 新鲜度以最近一次活跃正证据计算：一天内为 1，之后在约 60 天内线性衰减至 0；衰减本身不伪造新证据。

## 数据、撤销与回滚

schema 54 新增：

- `ai_interest_candidates`：聚合状态、支持/反证数、跨日本地主动证据数、置信度、新鲜度和当前版本。
- `ai_interest_evidence`：唯一事件簇、来源类型、来源引用、极性、权重、本地日期及撤销状态。
- `ai_interest_versions`：每次状态变化的不可变快照，用于审计和回滚。

用户删除模拟手机浏览器中的来源时，对应的兴趣证据会被撤销并重新聚合；删除不是简单隐藏。数据库同时提供显式停用和按历史版本回滚能力。三张表完整进入本地备份/恢复。

## 诊断隐私与真机验收

预检报告只输出候选/证据/状态/来源类型的聚合计数、跨日期候选数量、最新证据时间与实时新鲜度。它不会输出兴趣 key、标签、域名、URL、查询、来源 ID 或证据正文。

真机验收本包时应确认：

1. 从 v0.41.41 原地升级，聊天、记忆、世界书、相册和浏览记录均保持。
2. 一次真实自主联网后，`aiInterestEvidence.candidateCount` 与 `activeEvidenceCount` 增加，但 `establishedCount` 仍为 0。
3. 同一自然日内再次触发相同管线不会形成跨日期成熟；`crossLocalDateCandidateCount` 不应因此误增。
4. 下一本地日期对同一兴趣发生独立自主终态结果后，才允许出现 `autonomous_day_count >= 2` 和成熟候选。
5. 删除对应浏览记录后，`revokedEvidenceCount` 增加，候选重新聚合。
6. `promptConsumptionEnabled`、`topicSelectionEnabled`、`proactiveConsumptionEnabled` 始终为 `false`。

Snapshot protocol 继续为 5；本包只将数据库 schema 从 53 升到 54。
