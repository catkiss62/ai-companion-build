# Genie TTS 闪退热修与设置补齐 · v0.41.54

本候选包以同机三语通过的 Genie-TTS v0.6.4 APK 为唯一运行基线；不接入尚未真机验收的 v0.7 真流式实现。

## 三个独立选择

- `生成三语版本`：只决定以后生成的普通聊天回复是否保存中、日、英三个语义一致版本，默认开启。
- `显示外语正文`：只决定气泡显示外语正文还是中文权威正文；关闭不会删除外语版本，也不会改变语音语言。
- `中 / 日 / EN`：只选择当前消息的 TTS 语言。隐藏外语时选择日语或英语，界面继续显示中文翻译，播放队列只读取对应隐藏版本。旧消息缺少该版本时按钮禁用，绝不把中文送进外语前端。

## v0.6.4 初始化与播放安全

每次只保留一个语言前端。首次生成或切换语言时，先完成所选语言的前处理，再按需加载四个声学会话，然后串行推理。切换语言前释放旧前端和声学会话，避免 Chinese RoBERTa 初始化与旧声学模型形成额外峰值。

打断播放只暂停、清空并停止正在写入的 `AudioTrack`；对象由播放线程唯一释放，避免 UI 线程与阻塞写线程同时触碰已经释放的 native 状态。

危险阶段会在进入 Chinese RoBERTa、声学模型加载、推理及 AudioTrack 播放前同步保存脱敏诊断点。若系统仍以 native crash 结束进程，下次导出的诊断可以显示最后进入的阶段；源码仍不能在没有新真机结果前宣称闪退已经通过。

## 同包设置补齐

- 规则 01 的新安装默认改为 2026-09-09 用户备份正文；覆盖升级只迁移哈希精确等于 v0.41.53 默认的未修改行。
- 默认世界书为备份中的 `角色表达自然化`、`日常对话规则`、`性格光谱`、`造梗能力`；同名用户条目优先保留，避免重复创建。
- 知识、行为、角色扮演各自使用 30,000 字符正文预算。
- DeepSeek 模型选择增加 `自定义`，实际模型 ID 原样保存到既有 `model` 设置并用于连接测试和聊天。
- 中文 `token` 固定为“拖肯”（肯为轻音）；`DeepSeek` 固定为“地铺 C 咳”（铺、咳为轻音）。
