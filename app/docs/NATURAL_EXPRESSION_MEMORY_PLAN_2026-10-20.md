## 2. 六项修改范围

### A. 放松普通闲聊的表达压力

修改普通闲聊的行动提示：主动作、驱动、念头和话题方向提供可用材料与动机，不再要求每轮必须通过展开观点、延伸联想或索取回应来完成动作。允许一个应声、短反应、玩笑或自然停顿已经构成完整一轮。

保留她自己展开、换话题和主动表达的空间。用户话少不再被默认为需要程序替她补足一段内容；也不把“嗯、好、哈哈”硬编码为必须停止或必须继续。

明确任务、真实事实问题、认真求助的必要回应与工具结果交付照常。顺带核对问号/问词与任务关键词分支，避免把普通玩笑推成必须完整作答；没有已验证问题的分支不扩大重写，不新增逐轮语义判断请求。

保留现有来源选择、Thought/thread 生命周期、满足度核验及诊断。不能为放松措辞而删除共享行动选择或把“给了材料”算成“已经表达/消费来源”。

主要入口：`conversation_initiative_policy.dart`、`conversation_topic_policy.dart`、`dialogue_expression_plan.dart`、`prompt_builder.dart`。

### B. 普通聊天与主动消息统一动作规则

按用户偏好，普通聊天与正常主动聊天都以一段简短自身动作配合对白作为默认表现。动作贴合当下，可写尾巴、耳鳍、姿态、神态或语气；不增加场景叙事，不替用户补写动作或心思。

主动首发、事实修正重试，以及调用共用提醒的其他正文路径，统一传递动作规则。消除“前面允许/要求动作，末尾只允许对白”的矛盾。通知预览、TTS 和消息完整正文分别遵循现有展示职责，不用通知用语限制完整生成正文。

一轮一个动作是默认，不靠新增一次付费重写强行补动作。WAIT、取消、失败提示、纯工具状态及有自身格式要求的任务继续走相应协议，不能为凑动作产生额外消息。真正的状态与事实约束保留。

主要入口：`proactive_engine.dart`、`prompt_builder.dart` 及现有动作解析/展示边界。

### C. 精简口语规则，减少重复主题示范

在现有“角色表达自然化”中替换关于“口语化不等于信息少、句子短”的歧义措辞，正面说明：日常应声、短句或半句话可以是完整回应，按这次交流需要决定是否展开；认真解释时保证必要信息。保留不用堆语气词、结巴或故意错字来制造口语感的含义。

处理文体示意持续使用靠垫、轻微埋怨式亲近的单一方向。优先去掉非必要示例；确需示例时，只展示少量不同情境下的组织方式，不把嘴硬、关心或抖包袱设为统一结尾。保留既有世界书优先级、作用域和动作体系，不重写整个人设。

同步内置默认和既有用户内置条目的升级入口，沿用独立一次性版本标记；定点处理对应系统文档，保留ID、设置与用户自建条目，不重置整个世界书库。升级规则须检查用户自定义正文的现有保留策略，不盲目覆盖所有同名文档。

造梗模块继续可用，配置30%是注入机会，不是产出比例。此次不提高概率、不规定造梗次数、不强制执行十一种造法，也不因旧梗重复就把幽默整体关掉。

主要入口：`world_book_spoken_dialogue_v042108.dart`、`world_book_presets.dart`、现有内置文档升级路径。

### D. 保留自主成长，衔接旧AI Self与可修订的自我理解

区分三种作用：真实经历证明发生过；用户许可提供相处空间；自身表达倾向属于可以保留、细化或改变的理解。用户允许斗嘴不转成每轮必须嘴硬，曾经喜欢记账式玩笑不转成所有关心都要这样说。

实施先检查从候选检索、过滤、最终提示到普通整理写入的实际路径。召回计数不能作为最终模型采用的证据；补充必要的本地结构化准入/来源诊断，避免凭存在某条记忆就动数据。诊断不把私有正文写入公开仓库，也不在聊天界面显示内部标签。

读取侧：对已能由现有语义类别、主题、来源及状态识别的表达习惯，按情境化旧观察提供，避免沿用“永久固定表达”的指令含义。仍可参考她当前认可的稳定倾向，不把全部AI Self一刀切变弱。身份、真实拥有的资料、独立兴趣、价值理解分别保留各自意义。尤其不能全局修改 `ai_self -> stable` 共用回退而误伤稳定事实。

写入侧：检查单轮观察是否按现有约定保留为暂时认识；只在确有缺口的地方补语义/来源保护。复用已有梦境的 `understanding/choice/uncertainty/evidence` 和修订机制，表达理解可以包含适用条件、例外与反例。重要单次经历也能改变她，不以重复台词次数替代新经历，不增加每轮模型调用或额外人格评分。

旧记录先通过应用正确使用，不批删、不整库降权、不人工替她编新性格。若实施时证明确有少数过宽条目仍被当固定指令采用，先登记实际条目、来源和具体路径，再给出窄修范围；本方案不预先包含批量改写存档或重置人格。

主要入口：`memory_brain.dart`、`memory_grounding_policy.dart`、`memory_extractor.dart`、`dream_contract.dart`、`dream_material.dart` 和必要的数据库准入函数。

### E. 增加后台回看后的短期回忆上下文

复用已有后台空档调度，优先用本地选择和现有真实记忆内容准备少量回忆，不增加一套每轮运行的Agent或新的付费整理任务。

候选以有来源、当前有效的真实经历为主，覆盖她自己的真实探索和共同经历。结合当前关注与久未使用程度，兼顾主题分布；不能在候选限额前永远只取重要性最高的一批，也不能让游戏、亲密称呼或记账旧梗长期占据全部位置。缺少合适资料时跳过，不编造回忆、不恢复已归档/删除内容。

暂存来源ID、版本/修订、原事件时间和短期有效范围，生成前重新读取并验证来源。上下文提供经历，不附“因此你现在应该吐槽/撒娇/找某话题”的表达指令。回忆可以影响理解与联想，也可以完全不采用；不得自动发主动消息、创建待办或形成常驻人格。

拟采用的保守初始参数：每天最多准备一批，每批最多2条，24小时过期；每轮最多带入1条，同一条在一次成功交付后退出本批，至少7天不因后台轮巡再次挑中。当前话题明确需要它时，普通相关检索仍可照常召回。参数只控制资源和重复，不要求她每天必须回忆或固定说法。

消费与失效：失败、停止、事实修正重试不能制造多次新回忆；成功提交与消费绑定。导入/切换存档、删除、更正或来源版本变化后清理失效暂存，不能把旧缓存带入另一份存档。实现优先复用现有本地设置和工作栅栏，不为少量暂存先做大规模schema改造。

独立记录“后台准备/本轮提供/正文是否实际提及”，不把三者混为一谈。回看不刷新事件时间，不增加事实证据、人格置信度或记忆重要性；内部缓存引用不作为新的经验整合素材。已有SelfDrive的Thought与drive更新不额外再执行一遍。

主要入口：`self_drive_engine.dart`、后台heartbeat、`prompt_builder.dart`、相应来源校验/清理与诊断；梦境继续承担自我理解修订，不被动变成每日回忆汇报。

### F. 主动话题提供具体材料，并补愿望诊断

主动选题区分“想联系”与“已经有一件想聊的事”。好奇欲望本身不伪装成已有话题。优先利用真实念头、兴趣、发现、经历与新加入的回忆材料，提供具体着眼点；材料是选择空间，不规定她按步骤介绍、解释、提问。

没有具体内容时，仍可依原规则表达想念、轻问近况、简单接触或等待，不强制禁止家常，也不为保证每条主动都有新话题而编造见闻。保留主动频率、时机、夜间/起床、分享独立额度等现有规则，不凭空压低或提高发送数量。短期回忆不能自动变成新的强制分享来源。

愿望单只补新提议的可区分判因：未提出、重复、容量不足、字段/类别不合法、证据要求不满足、其他校验拒绝、请求失败等；复用已有请求和本地校验，不增加付费请求。特别区分模型没有提出互动愿望和提出后没有保存。

此次不为互动愿望预留配额、不提高生成频率、不改12小时按尝试冷却、不承诺诊断能提高互动愿望概率。若实施时发现真实错误拦截，按具体证据另行记录处理，不能提前将缺席全归为代码漏洞。

主要入口：`proactive_engine.dart`、现有话题选择/呈现、`wishes/wish_engine.dart` 与现有诊断投影。

- 回忆暂存可在升级后自行建立，失效可丢弃，不是必须迁移的永久人格资料。现有导入导出需验证，不制造协议不兼容。
- 靠垫施受归属已由后续对话澄清，本轮不做指代修复，不固定谁必须当靠垫，不按称呼删记忆。
- 保留成长开关、梦境频率与已有来源保护；不增加性格并行轮盘、随机变性格或每日成长任务。
- 保留第二通道/失败重试、普通按需工具规划及明确任务完整交付；不改JEV规则、游戏厅三次/30分钟、对谈close/end或主动在途竞态。

- 备份、诊断、凭据、私密聊天及记忆正文不上传公开仓库；方案仅保留机制与必要证据结论。

## 4. 实施顺序与验证

按A/B/C先收敛生成要求，D衔接记忆语义，E增加小范围回忆，F完善材料与诊断。按职责分开提交、同一轮统一验证和构建，便于定位回归；不把每一小项都单独发APK。正式开始时按唯一总账登记真实实施范围与新版本。

| 验证场景 | 必须成立的结果 |
| --- | --- |
| 普通短应声、玩笑、话题已到自然落点 | 不因预选动作强制展开；也不硬编码停止；来源未表达不被误消费 |
| 认真讨论、明确工具任务、多步骤请求 | 必要内容与真实结果照常交付，按需规划不扩大到普通闲聊 |
| 主动首发、修正重试、既有降级路径 | 动作规则一致；完整正文、通知与TTS边界保持；WAIT/取消不产生动作补发 |
| 世界书升级与自建/自改条目 | 默认及对应升级生效，身份/设置/自建内容不被批量重置 |
| 表达倾向与稳定身份同时被检索 | 情境化理解可参考，真实稳定事实不被误降级；准入与最终提供可区分 |
| 重复自述与真实新经历 | 前者不重复增信；后者仍可形成、修订或撤回自我理解 |
| 久远有效经历与历史高分重复主题竞争 | 有限候选能覆盖久未使用资料，不反复只挑相同旧梗；没有合适条目可跳过 |
| 回忆准备、提供、用户实际看见的正文 | 提供背景不强制开题，不增加主动额度消耗、drive脉冲或每轮模型请求 |
| 停止/失败/重试/导入/删除/更正 | 不重复消费、不跨存档使用、不注入失效来源、不把回看当新事实 |
| 新愿望提议的不同结果 | 路由、拒绝和失败原因可分辨，互动类型未被人为预留/强制生成 |

自动验证覆盖行为边界与实际执行路径，不用“某句必须简短/必须幽默”的断言代替自然度验证。按项目要求完成定向回归、源码检查、全量测试、存档恢复、Android15与最终APK签名/资源验证。

自然度另看相同上下文比较与真机持续表现：能否自然停下、能否直接表达、旧梗是否减少而记忆仍准确、联想是否更有具体内容、动作是否保留。长度只是观察项，不能用少字、词语禁用或多造梗判定通过。本轮未进行真实模型对照，不宣称已验证收益。

最终交付时提供修复项列表、实际测试与构建证据、待真机验证项、APK及唯一总账更新确认；失败路线、回归风险和未实施项如实保留。
