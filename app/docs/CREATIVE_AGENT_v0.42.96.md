## 实现约定

- 主角色传递用户原始委托及简短创作说明。工作 Agent 只读本件作品需求、文件、工具结果和进度，拥有独立上下文；不注入全部人设、梦境或聊天历史。原话优先于委托摘要中的额外推断。
- 原生流式工具循环：读文件、分块写入、精确修改、保存计划、后台试玩、完成提交。工具参数错误和试玩报错反馈给模型修复。单个巨大 JSON 不再承担整个作品的传输/发布。
- 文件、完成的工具步骤和待执行工具记录原子保存；模型响应先落检查点再执行工具。进程恢复优先处理已保存的工具，不重复请求已完成的模型步骤。截断/断流不执行不完整调用，不破坏已有文件。
- 网络故障有界退避，格式错误带明确原因继续；额度/配置问题暂停；自动请求次数和连续失败有上限。手动停止、删除、导入和旧执行结果使用既有事务围栏，不自动复活用户停止的工作。
- 实际后台 WebView 反馈错误、DOM 检查及互动桥调用证据。检查绑定当前源码版本；修改后必须重测。模型自称完成不能直接发布。真实伴侣互动沿用宿主 choose/reveal，不能由随机台词冒充。
- SQLite 存档携带工作文件和检查点；导入进行中工作保持暂停，续做保留有效源码。工作错误提示区分有无实际草稿。作品原有成品、同局状态与最近版本不被半成品覆盖。
- 保留独立工作租约，不占用聊天租约。Android 强停期间不能运行，恢复执行环境后续做；不承诺无限后台存活。
- 脱敏诊断只记录步骤、结束原因、长度、用量和错误类别，不记录 Key、源码、私人原文或模型思考内容。
