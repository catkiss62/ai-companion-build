# UI 信息架构 v1

> 状态：规划已确认，尚未迁移代码。  
> 原则：这次不是换皮肤，而是先把功能放进稳定的分类，避免 Agent、情绪、MCP、Skills 和感知能力继续加入后，单页设置越来越难维护。视觉皮肤放在功能稳定之后。

## 1. 一级结构

| 一级入口 | 核心问题 | 当前/未来内容 |
|---|---|---|
| 她 | 她是谁、现在怎样 | 人格与外观、性格试穿、AI Self、情绪概览、她提出的自我修改建议 |
| 你们 | 关系如何延续 | 关系状态、记忆、未完话题、用户画像、共同经历 |
| 能力 | 她能做什么 | 模型、联网、识图、TTS、提醒、Agent 工具、MCP、Skills |
| 手机感知 | 她能感知什么 | 当前应用、轻视觉、通知、悬浮陪伴、逐应用感知权限、生命周期诊断 |
| 数据与高级 | 如何管理与排查 | 规则、记忆管理、导入导出、设备迁移、隐私安全、开发者诊断 |

推荐路由命名：

- `/companion`
- `/relationship`
- `/capabilities`
- `/perception`
- `/data-advanced`

## 2. 页面归属

### 她

- 人格与外观；
- 性格试穿与长期人格；
- AI Self / 自画像；
- 情绪、欲望、内在驱动的用户可见摘要；
- 低风险自我调整记录；
- 高风险自我修改提案与用户确认。

这里不展示模型供应商、API 参数或无障碍权限。

### 你们

- 关系阶段与共同状态；
- 重要记忆、温度记忆、待确认记忆；
- 未完话题和承诺；
- 用户画像及其修订记录；
- 共同经历与可回顾片段。

记忆的底层调试、批量删除、导出仍归“数据与高级”。

### 能力

- 对话模型、备用模型与 API；
- 网页搜索、网页整理；
- 识图；
- 本地 TTS；
- 提醒与定时行动；
- Agent 工具目录、工具权限、调用记录；
- MCP 连接；
- Skills 安装与启停。

“她知道自己有什么工具”由 Agent 能力目录提供，不通过提示词假装。

### 手机感知

- 当前前台应用名称；
- 轻视觉/无障碍连接状态；
- 通知监听授权与实际连接；
- 悬浮层/桌宠生命周期；
- 逐应用可见范围和敏感界面保护；
- 最近感知事件、错误码和脱敏诊断。

权限开关必须区分“系统已授权”“服务已连接”“最近成功事件”，不能只显示一个勾选框。

### 数据与高级

- 六大规则及其他运行规则；
- 数据导入、导出、备份与清理；
- 设备迁移；
- 数据保留与隐私控制；
- 高级记忆管理；
- Thought、Drive、情绪事件的开发者查看；
- 日志、诊断、版本与 CI 信息。

普通用户流程不应先看到内部状态表和调试参数。

## 3. 迁移约束

1. **只迁导航，不改业务语义**：第一次代码迁移只拆页面与路由，不同时重写记忆、人格、工具或数据库。
2. **单一数据源**：同一字段只能有一个真实存储位置；多个页面需要展示时共用 Controller/Repository，不复制状态。
3. **旧路由兼容**：迁移期保留旧入口别名或重定向，避免深链和返回栈失效。
4. **不做空壳按钮**：MCP、Skills、完整情绪引擎未实现前，不以可点击功能伪装完成；可以在规划文档中存在。
5. **诊断与普通操作分层**：状态摘要面向用户，原始事件/错误码放高级诊断。
6. **不为分类改数据库**：信息架构不是第二套状态系统。
7. **男性向关系逻辑不是 UI 文案皮肤**：她的需求、立场、自我修改提案必须来自运行系统，不靠页面上的“傲娇/叛逆”标签。

## 4. 实施批次

### IA-0：文档与路由地图

本文件。确认功能归属和迁移边界，不改代码。

### IA-1：五域外壳

- 建立五个一级入口与路由；
- 现有功能仍可复用原页面；
- 验证返回栈、深链、横竖屏、小屏和无障碍；
- 不改存储、不改提示词、不升数据库 schema。

### IA-2：拆分设置页

- 按五域拆出页面与 section；
- 抽出共享配置访问层；
- 消除重复开关与重复状态判断；
- 保证迁移前后配置值完全一致。

### IA-3：接入新系统页面

在功能真实完成后依次加入：

- Agent 工具目录与调用轨迹；
- 情绪事件摘要与自我修改提案；
- MCP 连接；
- Skills 管理；
- 更完整的逐应用感知权限。

### IA-4：视觉皮肤

功能结构稳定后再统一颜色、动效、图标、桌宠视觉与动作神态文本样式。括号动作文本换色可作为独立小项提前做，不等同于整套换肤。

## 5. 验收清单

- 所有旧功能都能在新结构中找到；
- 没有两个开关控制同一字段却显示不同状态；
- App 重启后值不丢失；
- 页面返回栈和深链正确；
- 小屏、字体放大、横屏不溢出；
- TalkBack/可访问标签可用；
- 轻视觉、通知与悬浮层分别显示授权/连接/最近事件；
- 不增加业务数据库迁移；
- 自动测试覆盖路由、配置读写和关键状态摘要；
- 迁移提交与情绪/Agent 业务提交分开，便于回滚。

## 6. 当前决策

现在就固定分类和迁移顺序是合适的：它能减少后续每加一个功能都继续扩大单页设置的成本。此阶段不值得做整套皮肤，也不应该把 UI 重构和情绪引擎、Agent 框架、MCP 一次混在同一提交中。
