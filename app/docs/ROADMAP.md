# AI Companion Roadmap

当前任务真源只有仓库根目录 [AI_Companion_当前总账.md](../../AI_Companion_当前总账.md)。本文件只保留稳定的阶段顺序，不复制版本、完成状态或 APK 信息。

1. 轻视觉三段健康诊断、精确时间/跨日 gap、服务模板检测、前台 App 名称只读感知。
2. Agent Tool Registry 与真实工具调用：现有搜索、网页读取、识图、规则读取、记忆/自画像提案和提醒。
3. 记忆时效、热度、叙事层、用户画像与可回滚自我修改。
4. 最小 Appraisal / Emotion Episode，并按固定回放判据决定是否扩建情绪引擎。
5. UI 五域迁移：先导航与页面归属，保持单一数据源；视觉皮肤最后。
6. MCP 与 Skill Registry：先有通用工具协议、权限、审计、超时和取消，再接外部能力。
7. 冻结或后置：HyperOS 文件选择器 Overlay 恢复、完整换肤和产品化发布工作。

专项设计与验收标准从 [DOCUMENTATION_MAP.md](DOCUMENTATION_MAP.md) 进入。
