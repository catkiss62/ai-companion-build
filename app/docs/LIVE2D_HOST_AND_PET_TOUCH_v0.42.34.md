## 问题与修复

1. **桌宠尺寸倒退**：+277 把绘制窗口恢复方形，`PetFrameView` 宽高适配使宽动画缩小。本版恢复已接受的宽窗口，不改帧文件、目标高度、147% 校准或 121% 基准。中央旧方形输入区域通过 ViewTreeObserver internal-insets 独立提交给 WindowManager；既有 PetTouchRegions 手势边界一致。诊断 `overlayPetTouchRegion` 输出实际窗口及触摸矩形或兼容错误。部分 ROM 对内部 API 的兼容性必须真机确认，失败不偷偷缩动画。
2. **导入后又提示缺模型**：旧 onError 会 rollback 首次候选，可能删掉刚导入的模型。本版渲染失败保留包及完整错误；导入后销毁旧视图，Dart revision 单次重建，消除重复 reload 和旧视图回调验证新候选的路径。仍保留导入替换的暂存/旧包恢复机制。
3. **无模型时启用就卡输入法**：Dart 先查询模型；没有模型不创建 PlatformView/GLSurfaceView。存在模型使用直接 Hybrid Composition，原生子树禁止获取输入焦点；编辑焦点/IME 弹出时暂停连续绘制；舞台高度补偿键盘 inset，减少 surface 反复缩放。不能用 CI 冒称用户手机已流畅。
4. **设置分类**：侧栏旧清理入口改为 Live2D 设置；聊天画面设置只保留分类跳转。独立页提供开关、导入状态/错误、Jev 动作开关、原装表情/动作/Wink/装扮、待机/静止/耳鳍/摸头、位置缩放/还原。动作控制针对已打开的聊天舞台。删除必须弹窗确认，取消不调用删除；确认后关闭 Live2D 并清除菜菜和旧 Sen 本地导入文件。
