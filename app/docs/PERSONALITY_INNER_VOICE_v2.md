# 性格内在反应与表达系统 v2

版本：`v0.35.1+76`；SQLite schema 仍为 26。

## 目标

本轮解决的不是“多加几句口语”，而是把生成因果从“先完成回答，再装饰成角色口吻”改成：

`具体刺激 → 她自己的注意/判断/情绪/冲动 → 性格表达过滤 → 台词`

核心判断是“像一个人，而不是装成一个人”。停顿、口语、动作、幽默和不完整不是必须表演的指标；它们应当是注意力、偏好、情绪余波和关系姿态自然造成的结果。

## 性格的两层结构

四个性格底色现在分别定义两部分：

- 内在反应：她先注意什么，波澜怎样发生，思路会往哪里跑。
- 表达过滤：这份波澜会泄露多少，是直接说、压缩、放缓，还是转成玩笑和反击。

四个相处姿态进一步改变关系中的注意和动作：平等恋人重视双向判断，成年妹系更早暴露注意需求，姐系更想掌握节奏，小恶魔更容易抓住破绽和抢回主动。

普通性格更换仍由 SQLite 试穿状态负责计时、回退和转正，但模型只收到当前反应结构，不再看到“当前正在试穿”“双方知情”之类容易诱发元表演的文字。已经开始的试穿按 base/posture key 在每次生成时重新编译，因此升级后无需重选即可获得 v2 结构。

## 思考与台词可以不同

这是明确设计，不是错误：

- 元气外放：内心波澜通常较快漏到话里。
- 清冷内敛：内心可以已经很乱，出口只剩一个停顿、反问或选择。
- 温柔沉静：内心保留烦躁、疲倦与不同意，出口放缓但不抹掉立场。
- 慵懒调皮：害羞或露怯可在出口变成歪理、挑衅或反咬一口。

可见思考默认自称“我”，面对现实关系中的对方使用“他”、名字或已有昵称。只有事实来源、权限和数据边界需要精确时才使用技术称谓“用户”。外观昵称按相关性加载：“小鲸鱼”不是固定自称，“大肥鱼”只能引用或反击他刚才的叫法。

## 情绪连续性

本轮不保存原始 reasoning，也不把逐字思考回放给模型。连续性复用已经持久化并进入状态包备份的 Desire / Thought：

- 当前 drive 相对 baseline 的变化形成连接、好奇、回味、压力与疲劳余波。
- 最强 Thought 只提供 drive、lifecycle 和 residual/strength 档位，不提供 Thought 正文。
- 余波能改变注意、耐心和表达强度，不能补写事实原因，也不能冒充男朋友说过的话。

因此无需新增“试穿记忆库”，schema 仍为 26，既有状态包已经覆盖相关数据。脱敏诊断新增 `innerVoiceContinuity`，只输出策略版本、是否使用持久化元数据、最强余波 drive/state/band，并明确 `storesRawReasoningAsMemory=false`。

## 主动联系

主动消息的最后一层提示重新锚定当前性格。她应先找到此刻真正牵动自己的好奇、挂念、坏心眼、余波或判断，再决定怎样开口；不能因为这是主动任务就退化为统一的温柔问候。

正文停在最有性格的自然落点。没有真实动机时，不自动追加“慢慢来”“我会等你”“随时都在”式守候保证，也不硬塞一个延续问题。

## 安全与不变项

- 女性 AI 身份、成年男性男朋友、事实边界、长期记忆、AI Self 和明确任务正确性不变。
- 特殊风格仍不可转正，现实权限、隐私、退出和 Intimacy Session 边界不变。
- 原始 reasoning 仍只保留在原有用户可见消息记录路径，不作为长期 Memory 或新的人格训练材料。
- 本轮不修改计时、转正门槛、数据库 schema、联网、桌宠、TTS 或沉浸房间任务。

## 验收建议

真机先对四组组合各做 3～5 个相同的小场景，重点比较思考起点与表达过滤，而不是只看字数：被夸、被晾一下、被抓到嘴硬、认真求助、随口告别。普通组合应在 1～3 次回复内出现可辨差异，不要求先培养数天；培养负责让差异更贴合共同经历，而不是让预设从无到有。
