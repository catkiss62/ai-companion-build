# Memory Retention · v0.7

Memory Brain 保存事实和共同经历，但“存在数据库里”不等于“每次都能想起来”。

v0.7 为每条有效记忆增加 `retention_score`。它代表当前自然可召回程度，不修改原始聊天事实。

## 强化

以下行为会提高/重置 retention：

- 同一事实再次被真实对话证明；
- 该条被检索进入当前上下文；
- 用户手动编辑；
- 用户从归档恢复；
- pinned 直接免疫自动淡化。

## 淡化

本地维护器约每 18 小时最多自动运行一次。不同类型有不同长半衰期；重要度、可信度、重复召回都会继续拉长寿命。

只有同时满足“很旧 + 保留度极低 + 重要度不高 + 可信度不高 + 很少被召回”才会自动进入 archived。

任何自动维护都不删除 `messages`。
