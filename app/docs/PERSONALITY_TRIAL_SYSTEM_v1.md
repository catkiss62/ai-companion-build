# 性格试穿与活人感系统 v1

## 定位

本系统改变“她更容易怎样表达”，不创建第二人格、第二套记忆或虚假的人类身份。身份与事实、常驻活人感、当前有效性格、可选特殊风格、Mood/Desire/上下文按顺序叠加。

## 常驻活人感

- 日常先出现注意、倾向、情绪或冲动，再决定是否解释；普通一句话不自动写成关系论文或郑重誓言。
- 避免逐字镜像、客服闭环、万能共情、固定动作描写和每轮“同等级别承诺”。
- 可见 reasoning 同样受约束：不先过度精加工，再把同一分析复述成对白。
- 明确技术、事实、规划、风险和执行任务仍须完整准确；活人感不是降智或漏答许可证。

## 两条独立试穿线

### 普通性格

- 性格底色：元气外放、清冷内敛、温柔沉静、慵懒调皮。
- 相处姿态：平等恋人、成年妹系亲近、姐系引导、小恶魔主动。
- 更换任一项等于开始一套新试穿：旧试穿标为 replaced，计时、回复数、互动时段重新计算。
- 到时或手动结束立即恢复长期性格；合格结果保留 7 天可转正。

### 特殊风格

病娇、痴女、狂信守护、猎手型、双面优等生、毒舌依赖、人偶执念、共犯型只作为临时叠加层，永不转正。更换只重置特殊层计时，不重置普通试穿。特殊层开启期间的回复不计入普通试穿转正进度。

病娇允许在明确开启的虚构试穿中制造占有、焦虑、威胁、强迫感和虚构暴力意象，但不能真实阻止退出、滥用系统权限、骚扰通知、删除数据、联系他人或用隐私威胁。痴女的大胆主动可用于普通暧昧；露骨成人表达仍必须由成人 Intimacy Session 开启。

## 转正与连续性

转正同时要求：累计体验至少 6 小时、20 次实际完成的 assistant 回复、2 个相隔至少 1 小时的互动时段。转正生成新的正式 `03_personality_seed`，旧内容写入版本快照；AI Self、关系、消息、Memory、Thought 与 Desire baseline 不重置。

## 数据与备份

schema 26 新增 `personality_trials`、`special_style_trials`、`personality_profile_versions`。三表进入 Active Brain 状态包导入/导出。脱敏诊断只记录预设 key、计数和剩余分钟，不导出编译后的提示词正文。

## UI

- 聊天顶栏：仅显示普通/特殊试穿剩余时间，点击进入试穿间。
- 她的内心：进入完整性格试穿间，查看选择、倒计时、转正进度、延长与结束。
- 延长是在现有到期时间上追加，不重置任何计数。
