# DeepSeek Live2D第一阶段：隔离与校准

目标v0.42.154+398/schema67，当前是源码候选，CI/签名APK尚待验证。基线92863026；工作区完整树已核验为远端1a171903，再开始修改。此前+397通道加速、识图分流和分享修复保留。

## 本阶段

- 设置页增加菜菜/DeepSeek选择，导入、资源索引和删除均限定当前模型。菜菜目录/偏好名保持；DeepSeek独立目录，识别单模型结构与参数签名，支持本包GBK名称及标准UTF-8 ZIP。
- DeepSeek独立单模型驱动，读取真实Core参数范围和作者物理。保留原贴图，GL_LINEAR、目标60FPS和512px高精度蒙版沿用既有基准；不压缩、不降采样。切换沿用已有GL框架所有者的串行释放，不同时驻两套纹理。
- 新模型用会话身份和真实首帧确认。A→B→A、旧view、旧JEV和旧编辑器命令失效；成功显示后才持久确认选中模型。加载失败保留原资源与上一次成功选择，重启/重新选择可返回。
- DeepSeek位置/缩放/幅度/速度/小腿轴、两种眼镜、裙长、鞋和嘴型独立保存；胸口/尾巴固定0。菜菜稳定手动装扮补上保存，原预设及默认值不改。
- 参数预览读取真实范围，支持组合；预览不存为默认。单独提供小豆丁0.8、正常0、变身锚点、绕小腿旋转及左右位移预览。锚点取DeepSeek自身网格，首版坐标仍需手机校准。
- 真实PCM播放时口型由音频控制。DeepSeek校准版暂不接菜菜JEV/道具/语义表情；不会为它额外购买菜菜规划。
- 原生保存显式区分旧三组配置与新profile版本，旧档未声明DeepSeek时保留其设置。普通存档仍外置模型文件；新档记录两套配置和模型指纹。导出不重载，同模型恢复设置热更新，真正改变模型选择才重建一次。

## 验证范围

新增Robolectric生产仓库/偏好测试覆盖GBK导入、模型隔离、错误包不覆盖、A→B→A迟到确认、旧档保留DeepSeek、回滚、只读导出、新旧格式与待确认导入围栏；Flutter覆盖切换身份、删除目标、恢复选中模型和导出不重载。沿用现有菜菜、恢复、Android15原生与完整CI，不以静态源码校验代替原生效果。

本地缺Flutter/Android构建环境及由CI恢复的部分资源包，完整验证必须由CI完成。原生兼容、实际画面、扶胸等作者手势效果、真实帧时/内存尚未在用户手机验证，不宣称已达恒定60FPS。

## 手机校准顺序

1. 覆盖安装后先选菜菜，确认原位置、衣服、耳鳍/呆毛/尾巴和聊天动作保留。
2. 选DeepSeek，在该槽位导入原DeepSeek.zip，启用后返回聊天等待首帧；模型素材无需打进APK。
3. 在DeepSeek设置预览主要轴、正常/小豆丁、小腿左右倾斜及位移；用变身中心调节颈部/领口附近的锚点。
4. 两套各改不同设置，切换、重启，再导出/恢复存档，确认互不覆盖。反馈异常时导出Live2D诊断，不需要重新发送原素材。
