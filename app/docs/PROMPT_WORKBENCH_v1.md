# Prompt Workbench v1 · v0.35.2+77

## 目标

把所有会直接塑造 AI 身份、关系、日常表达、性格试穿、特殊风格、记忆使用和可见思考的“设定类 Prompt”集中暴露出来。普通聊天沿用 `01 身份核心 / 02 日常说话规则 / 03 性格底色 / 04 记忆规则 / 05 NSFW 状态机 / 06 NSFW 渲染`，v0.39.0 新增只在独立小说场景加载的 `07 沉浸房间`。运行数据、聊天、Memory 实际内容、Desire 数值、API Key、权限与设备身份不属于设定包。

## 单一真源

- 继续使用既有 `rule_layers`，不新建第二人格库或试穿记忆库。
- UI 显示七张卡片，每张卡片进入一个完整长文本框。底层小节用稳定中文标记路由：01 合并身份/关系/外观/身份事实，02 合并日常/行为真实感/可见思考/主动轮次，03 合并长期种子与全部试穿模板，04 是记忆规则，05 是 NSFW 状态机，06 合并普通聊天的 NSFW 渲染与参考资料，07 是沉浸房间的全局运行协议与成人小说参考。
- 历史 `07_*`/`08_*` 仍是性格试穿或运行模板的稳定 key，不机械改名；它们继续显式映射到规则03/01/02。新规则07使用独立的 `immersive_07_*` 语义键，避免数据库迁移和分组歧义。
- `load_policy=template` 的行不会独立注入 Prompt，只在当前试穿/特殊风格/生成模式被选择时装配。
- 正在运行的试穿每轮按 key 重新装配，因此编辑 07 后下一轮生效，不重置倒计时、转正进度、AI Self、Memory 或 Desire baseline。
- `04 · 记忆规则` 不只显示在聊天 Prompt：真实的经验整合器与 AI Self 反思也会读取同一正文；固定 JSON 结构、证据校验和数据库提交围栏仍由代码保护。
- `02 · 日常说话规则` 内的主动轮次小节同时包含主动开口的表达要求；主动引擎不再另藏一份同义风格 Prompt。

## 保护常驻

旧 `locked` 语义改为“保护常驻”：不能关闭，但内容可以编辑、导入和恢复默认。App 启动或打开列表时不再覆盖用户修改。

权限、停止、退出、隐私、Active Brain、transfer lock、run token、数据库事实来源与成人 Session Gate 是代码约束，不伪装成可导入 Prompt，也不会被文本覆盖。

## 编辑器与中文选择菜单

- App 与启动恢复页显式使用 `zh_CN` 和 Flutter 官方本地化 delegate，复制、剪切、粘贴、全选等使用系统/Flutter 自适应中文菜单。
- 长文本不再放在 AlertDialog 的 14～28 行嵌套滚动区，而使用全屏固定视口 `TextField(expands: true)`、独立 ScrollController 与 Android 风格 clamping 滚动，避免选择文字向上拖到边界时反复回弹。
- 页面只有七张规则卡片；点一张卡片才进入这组唯一的全屏输入框，避免几十个小输入框。

## 设定包

“复制全部设定包”输出 `ai_companion_prompt_pack` JSON；“从剪贴板导入”只接受相同格式和当前已知 key，先显示变更数量并要求确认。保护常驻项不能通过导入关闭。包内不含聊天、记忆、欲望状态、API Key、权限或设备数据。

## 和她讨论

每个小节提供“和她讨论”。用户写明希望调整的方向后，DeepSeek 以第一人称返回修改理由和完整提案；提案只进入编辑器，必须由用户再次点击保存才能生效。模型不能静默修改自身设定。

## 聊天生成参数

- `AI 与陪伴设置` 露出“模型思考模式”和 `Temperature 0.0～2.0`，默认分别为开启与 `1.0`。
- DeepSeek 官方 Chat Completions 在思考模式下会忽略 Temperature，因此界面直接说明：保留可见原生思考时数值只保存；关闭思考后才实际发送并生效。
- 该组参数作用于普通聊天、图片识别后的回复、断点恢复和主动开口；网页摘要、记忆抽取、AI Self 整理和“和她讨论”的 JSON 提案保持各自稳定参数，避免事实维护随对白随机性一起漂移。
- Temperature 是运行参数，不是提示词正文，不进入七大规则设定包。

## 真机验收

1. 长按中文正文时菜单为中文；复制、剪切、粘贴、全选可用。
2. 选中长文本后从底部向顶部拖动，顶端不持续回弹。
3. 页面严格只有七个规则框；性格试穿与高级提示都在对应规则框的同一长文本中可见、可编辑，历史 `07_*` 模板仍属于规则03。
4. 修改正在试穿的 07 条目后，下一轮采用新文本且倒计时不重置。
5. 设定包导出后可原样导入；聊天、记忆、Key 和设备信息不出现。
6. “和她讨论”只能生成待确认提案，未点保存时运行时内容不变。
7. 思考开启时请求不携带无效 Temperature；关闭思考后请求携带当前 0.0～2.0 数值，主动开口也采用同一聊天设置。
