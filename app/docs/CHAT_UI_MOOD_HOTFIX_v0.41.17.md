## 1. 聊天文字层级

- 普通聊天与沉浸房间的用户正文、AI 正文、主动消息状态和输入框已输入内容保持白色；输入提示、时间与解释文字仍可使用次级灰。
- 普通聊天顶部头像旁和快捷侧栏头像旁的 `DeepSeek` 保持白色。全局说明文字的语义灰不得再次穿透聊天正文。
- 主动延续标签使用“她 · 想起刚才的话”，不再写成“续上次的话”或带“状态：”前缀。
- reasoning 折叠头统一为小三角加字距展开的 `THINKING`；收起向右、展开向下。普通与沉浸共用同一 Flutter 组件，原生悬浮聊天使用简化同义外观。

## 2. 对白颜色共享设置

- `文字演出`提供浅紫 `#D2C3EB`、浅黄 `#FDE68A`、浅粉 `#F1B7C5` 三种对白 `「」` 颜色，默认浅紫。
- 单一 App setting key `chat_dialogue_color` 同时控制普通聊天、沉浸房间，并把同一选择同步给原生悬浮聊天；普通动作括号与非对白正文仍为白色。
- 设置只改变显示颜色，不改消息正文、TTS 分句、Memory、Prompt 或备份协议。

## 3. 心情、购物车与关系天数

- `MoodChart` 自身必须在 Column 等松散横向约束下占满可用宽度，不能依赖父页面碰巧传入宽度；最近七日标签和节点不得全部堆到左边。
- DeepSeek 购物车每项可返回相关 emoji；解析器拒绝明显正文或异常长字段。缺失或非法时按商品关键词与稳定索引选择多样兜底，不得把全部商品统一显示为包裹。
- 快捷侧栏在“查手机”上方显示认识第几天，直接复用数据库 `relationshipAge()` 与 `relationship_started_at`，不创建第二套起始日期或计时逻辑。
